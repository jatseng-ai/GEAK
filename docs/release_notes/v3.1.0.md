# GEAK v3.1 Release Notes

## Highlights

**RAG-powered knowledge integration (MCP-based)**
GEAK introduces an MCP-based RAG system that provides dynamic access to a curated GPU optimization knowledge base (ROCm/HIP stack, architecture insights, optimization patterns). Retrieved context is injected directly into the optimization loop, improving reasoning quality and convergence.
A reverse pipeline supports offline knowledge ingestion and continuous updates.

**Cross-session memory and retrieval**
GEAK now persists optimization history across runs. Historical kernels, patches, and strategies are indexed for similarity-based retrieval, allowing new optimizations to bootstrap from prior results rather than starting from scratch.

---

## Changes since v3.0.0

**Knowledge-aware optimization**
The optimization loop is now grounded in structured GPU knowledge via RAG, improving strategy selection and reducing blind exploration.

**Persistent memory system**
Introduces cross-run memory with similarity search over past optimization trajectories, enabling reuse of effective patterns on recurring workloads.

---

## Requirements

* Python ≥ 3.10
* LLM access (e.g. LiteLLM or AMD LLM Gateway)
* Optional: Docker environment via `scripts/run-docker.sh`
