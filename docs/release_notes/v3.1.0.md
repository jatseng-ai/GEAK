# GEAK v3.1.0 Release Notes

## Highlights

### RAG-powered knowledge integration (MCP-based)
GEAK introduces an MCP-based RAG system that provides dynamic access to a curated GPU optimization knowledge base (ROCm stack, architecture insights, optimization patterns). Retrieved context is injected directly into the optimization loop, improving reasoning quality and convergence. A reverse pipeline supports offline knowledge ingestion and continuous updates.

### Cross-run memory and retrieval
GEAK now carries optimization memory across runs. Historical kernels and strategies can be stored and retrieved through similarity search, allowing new runs to start from prior experience instead of optimizing from scratch.

### Clearer optimization logs
GEAK improves logging throughout the optimization workflow. Users can more easily follow what the agent is doing, inspect optimization progress step by step, and understand the current state of a run while kernel optimization is in progress.

---
## Changes since v3.0.0

- Integrated MCP-based retrieval into the optimization loop, with offline knowledge ingestion support
- Introduced cross-run memory with similarity-based retrieval over past optimizations
- Improved runtime stability and usability:
  - Reduced MCP-related race conditions and CLI blocking issues
  - Better environment compatibility (Docker, paths, shell)
- Strengthened preprocess and harness robustness:
  - Improved harness validation and fallback handling
  - More reliable baseline and evaluation execution under varied conditions
- Added initial support for reusable agent skills

## Requirements

- Python >= 3.10
- Access to an LLM endpoint (for example, LiteLLM or AMD LLM Gateway)
- Optional: Docker environment via `scripts/run-docker.sh`
